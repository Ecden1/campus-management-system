# 微校园学生信息管理系统

基于 Flask 的轻量化学生信息综合管理 Web 平台，采用 C/S 桌面客户端架构设计。

## 技术栈

- **后端框架**: Flask 2.0.1
- **数据库**: MySQL + SQLAlchemy
- **前端**: Bootstrap 4 + Jinja2 模板
- **数据处理**: openpyxl (Excel 导入导出)
- **密码加密**: Flask-Bcrypt

## 项目结构

```
campus_system/
├── app/
│   ├── controllers/     # 业务逻辑控制器
│   ├── models/          # 数据模型
│   ├── views/           # 表单和路由蓝图
│   ├── templates/       # HTML 模板
│   └── static/          # 静态文件
├── config/              # 配置文件
├── data/                # 数据存储
├── requirements.txt     # 依赖包
├── run.py              # 应用入口
└── init_db.py          # 数据库初始化脚本
```

## 安装步骤

1. **安装 Python 依赖**
   ```bash
   pip install -r requirements.txt
   ```

2. **配置 MySQL 数据库**
   - 创建数据库 `campus_system`
   - 修改 `config/config.py` 中的数据库连接信息

3. **初始化数据库**
   ```bash
   python init_db.py
   ```
   - 默认管理员账号: admin / admin123
   - 默认教师账号: teacher / teacher123

4. **启动应用**
   ```bash
   python run.py
   ```

5. **访问系统**
   - 打开浏览器访问: http://localhost:5000

## 功能模块

### 1. 用户认证与权限管理
- 用户登录、注册、退出
- 基于角色的权限控制（管理员/教师/学生）
- 操作日志全程记录

### 2. 学生档案管理
- 学生信息增删改查
- 批量导入导出（Excel）
- 数据格式校验、重复拦截

### 3. 班级管理
- 班级信息维护
- 班级与学生关联管理

### 4. 课程管理
- 课程信息维护
- 课程代码、学分管理

### 5. 成绩录入统计
- 成绩录入（平时成绩 + 期末成绩）
- 总评成绩自动计算（平时*40% + 期末*60%）
- 成绩锁定/解锁功能
- 成绩范围校验（0-100分）

### 6. 学籍异动管理
- 学籍状态变更（在读、休学、复学、转学、退学、毕业）
- 异动原因记录
- 历史异动查询

### 7. 数据查询与报表
- 班级学生报表导出
- 课程成绩报表导出
- 统计信息（平均分、最高分、最低分、及格率）

### 8. 系统安全审计
- 登录日志、操作日志、异常日志
- 多条件查询审计记录
- 操作可追溯、可审计

## 注意事项

1. 成绩录入后需要锁定才能有效归档
2. 已锁定的成绩无法修改或删除
3. 只有管理员可以访问安全审计模块
4. 敏感信息（身份证号、手机号）建议在生产环境中加密存储
