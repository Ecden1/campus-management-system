# campus-management-system 校园管理系统

微校园学生信息管理系统，基于 Flask + Python 开发的软件工程课程设计项目。

## 项目简介
本系统是一个面向高校的学生信息管理平台，实现用户认证、学生档案管理、学籍异动、成绩录入与统计、系统安全审计等功能，采用 MVT 分层架构，结构清晰，便于扩展与维护。

## 技术栈
- 后端：Python 3.x / Flask
- 数据库：SQLite
- 前端：HTML / Jinja2 模板引擎 / Bootstrap
- ORM：Flask-SQLAlchemy

## 核心功能
- 用户登录与权限控制（管理员、教师、学生角色区分）
- 学生档案增删改查、导入导出
- 班级与课程管理
- 学籍异动管理（休学/复学/退学等）
- 成绩录入、计算与统计
- 系统操作日志与安全审计

## 运行环境
- 操作系统：Windows 10 / Windows 11
- Python 版本：3.10+
- 依赖库：Flask, Flask-SQLAlchemy, Flask-WTF
